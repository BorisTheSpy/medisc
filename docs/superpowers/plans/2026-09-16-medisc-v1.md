# Medisc v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a Cloudflare-hosted, local-first disc golf scorecard web app with nearby-course discovery, course maps, round history, and a stats dashboard.

**Architecture:** React SPA (Vite 8, TypeScript, Tailwind 4) with Dexie/IndexedDB persistence and pure domain modules for scoring, stats, OSM parsing, and geo. A tiny Hono Worker proxies and caches Overpass. Served as Cloudflare Workers Static Assets via `@cloudflare/vite-plugin`.

**Tech Stack:** react 19, react-router 8, dexie 4 + dexie-react-hooks, maplibre-gl 6, recharts 3, lucide-react, date-fns 4, vite-plugin-pwa, hono 4, wrangler 4, vitest.

Spec: `docs/superpowers/specs/2026-09-16-medisc-design.md`.

## File structure

```
medisc/
  wrangler.jsonc               Worker + assets config
  vite.config.ts               react, tailwind, cloudflare, pwa plugins
  worker/index.ts              Hono app: POST /api/overpass with endpoint fallback + Cache API
  public/_headers              security headers for static assets
  public/icons/*               PWA icons (SVG-generated PNG)
  src/main.tsx                 router + providers
  src/index.css                Tailwind import, @theme tokens, light/dark
  src/domain/types.ts          Player, Course, Hole, Round, HoleScore, Zone
  src/domain/scoring.ts        toPar, scoreLabel, strokesFromThrows, roundTotals
  src/domain/stats.ts          overview, distribution, form series, bests, throw stats, per-course, head-to-head, streak
  src/domain/osm.ts            parseNearbyCourses, parseCourseHoles, query builders
  src/domain/geo.ts            haversine, bearing, formatDistance
  src/db/db.ts                 Dexie schema
  src/db/repo.ts               create/update helpers (uuid, timestamps)
  src/db/hooks.ts              useLiveQuery wrappers
  src/services/overpass.ts     fetch via /api/overpass with direct fallback + cache table
  src/services/nominatim.ts    place search
  src/services/useGeolocation.ts
  src/map/CourseMap.tsx        MapLibre wrapper: basemap/satellite toggle, hole layers, user dot, focus hole
  src/map/style.ts             style URLs and satellite raster source
  src/components/*             AppShell, TabBar, Button, Sheet, ScoreChip, StatTile, EmptyState, ...
  src/routes/*                 Onboarding, Home, Courses, CourseDetail, CourseEdit, NewRound, Scorecard, RoundSummary, Rounds, Stats, Settings
  src/lib/format.ts            date and number formatting
  tests/*.test.ts              vitest for domain modules
  tests/fixtures/*.json        real Overpass responses
```
